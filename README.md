## Project Overview
The **UK E-Sports League Platform** is a data-driven web application designed to simulate a professional competitive gaming ecosystem.

The platform allows players, teams, and administrators to interact with dynamic data through a modern, responsive interface backed by a secure database system.

---

## Platform Features

### Homepage & League Overview
- Modern, high-energy UI design  
- League statistics such as active players, teams, and community engagement  
- Clear navigation for users entering the platform  

---

### Teams & Community
- Professional teams representing different regions  
- Interactive team cards with hover effects  
- Community-focused structure reflecting a real e-sports league  

---

### Player Search & Analytics
- Advanced player search by name, ID, or team  
- Dynamic filtering system  
- Player performance data including match history and statistics  
- Modal-based profile display for smooth user experience  

---

### Registration System
- User registration form connected to the database  
- Secure data storage for player records  
- Eligibility for teams, tournaments, and stat tracking after registration  

---

### Merchandise & Rewards
- Integrated store system  
- Add-to-cart functionality  
- Free claim rewards with email verification  
- Dynamic cart updates using backend logic  

---

### Admin Panel & Security
- Secure admin login system  
- Backend management of players and records  
- Administrative control for maintaining fairness and integrity  

---

## Technologies Used
- HTML5  
- CSS3  
- PHP  
- MySQL  
- XAMPP (Local Development Environment)

---

## Database Information
- Database file: `esports.sql`  
- Database connection: `dbconnect.php`  
- MySQL used for structured data storage and retrieval  

---

## How to Run the Project
1. Install **XAMPP**
