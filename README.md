## Project Overview
The **UK E-Sports League Platform** is a data-driven web application designed to simulate a professional competitive gaming ecosystem.

The system allows players, teams, and administrators to interact with structured data through a responsive interface supported by a secure backend database.

---

## Platform Features

### Homepage & League Overview
- Modern and engaging user interface  
- League statistics such as registered players and teams  
- Simple and clear navigation structure  

---

### Teams & Community
- Professional teams representing different regions  
- Interactive team cards with hover effects  
- Community-focused layout inspired by real e-sports leagues  

---

### Player Search & Analytics
- Search players by name, ID, or team  
- Dynamic filtering system  
- Player performance records and match statistics  
- Modal-based profile display for better user experience  

---

### Registration System
- Player registration form connected to the database  
- Secure storage of user information  
- Registered users become eligible for teams and statistics tracking  

---

### Merchandise & Rewards
- Integrated merchandise store  
- Add-to-cart functionality  
- Free reward claim feature with email verification  
- Dynamic cart updates using backend logic  

---

### Admin Panel & Security
- Secure admin login system  
- Backend management of player records  
- Administrative controls to maintain data integrity

## How to Run the Project
1. Install **XAMPP**
2. Place the project folder inside the `htdocs` directory
3. Import `esports.sql` into **phpMyAdmin**
4. Start **Apache** and **MySQL**
5. Open a browser and visit:  
   `http://localhost/datadrivenfullstackdev/`
